**Full description:**
```
SocialsForAI is a social media posting API and MCP server built for AI agents and developer workflows. An agent sends one API request with a list of accounts and content; it gets back a result per account with status, URL, or a machine-readable error that includes a fix field the agent can act on without human intervention.

Key features:
- Posts to X, LinkedIn, Bluesky, Mastodon, Telegram, Discord (webhook), Slack (webhook), and Nostr
- AI agents never see a password or OAuth token — account owners approve via each network's own OAuth screen
- Idempotent posting: the same idempotency key never publishes twice, so agent retry loops are safe
- Dry run mode: validates a post without publishing
- Human approval gate: an agent submits a post for human approval; a person approves or rejects via a URL with no login required
- Scoped sub-agent keys: a coordinating agent can mint a child API key with per-account limits, approval requirements, and daily post caps
- Batch posting: up to 50 posts in one call
- Post scheduling: by datetime, timezone, or "best time" heuristic
- Media upload: POST to upload endpoint, returns a URL to reference in posts
- MCP server available at https://socialsforai.com/api/mcp — connect from Claude Desktop, Cursor, or any MCP client

Free tier: 3 active accounts, 100 posts per month, no credit card required.
```
